# Técnicas Computacionais: Inteligência Artificial na Escola

Este repositório contém um projeto sobre o uso de **Inteligência Artificial** na educação. Explore como essas tecnologias podem transformar o aprendizado, otimizar a gestão educacional e facilitar o trabalho dos educadores.

## Acesse o site

Visite a página inicial do projeto, com mais informações e exemplos de aplicação:

[https://github.com/seu-usuario/Tecnicas-Computacionais-IA-na-Escola](https://github.com/seu-usuario/Tecnicas-Computacionais-IA-na-Escola)

## Estrutura

- `index.html` - Página inicial do projeto.
- `style.css` - Estilo para a página HTML.
- `notebooks/` - Jupyter Notebooks e códigos de exemplo.
- `src/` - Implementação de soluções de IA.
- `docs/` - Documentação teórica sobre IA na educação.

## Como executar o projeto

1. Clone o repositório:

    ```bash
    git clone https://github.com/seu-usuario/Tecnicas-Computacionais-IA-na-Escola.git
    ```

2. Abra o arquivo `index.html` em um navegador.
